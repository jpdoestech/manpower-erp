## Plan and files (before coding)

1. Write ADR-011 authentication/MFA plan, extend DECISIONS and security matrix.
   Identity is global; authentication grants no company/role/approval authority.
2. Add app/identity models/security/service/routes/CLI and migration 0002_identity.
   Tables: users (UUID, unique normalized username, Argon2id hash, active flag),
   hashed opaque sessions (8-hour fixed expiry/revocation), DB login-limit windows,
   authentication audit events. No company/financial schema. Explicit transactions.
   Enforce append-only auth events with a PostgreSQL statement trigger rejecting
   UPDATE/DELETE/TRUNCATE; privileged DDL tampering remains a deployment concern.
3. Only operators provision/deactivate/reset accounts through CLI with hidden,
   confirmed password prompts. No signup, user list, admin API, default credentials
   or user-supplied roles. API: POST login/logout/password, GET me.
4. Secure-by-default HttpOnly/SameSite=Strict cookie; local HTTP opt-out only for
   loopback origin. Validate explicit origin on browser mutations; require a
   session-bound CSRF header for logout/password. Store only token SHA-256 hashes;
   derive the CSRF value using HMAC with the random session token as the key.
   No bearer token in localStorage/JSON. Reject expired/revoked/inactive sessions.
5. Argon2id via argon2-cffi (minimum 19 MiB/2 iterations/1 lane); passwords 15–128
   characters, no truncation/normalization/composition rule. Generic failures and
   dummy verification for unknown usernames. DB-backed limits: 5 login attempts
   per normalized username per 15 minutes, 60 total/minute, serialized by upsert.
   Current-password changes also consume the credential-attempt limit.
6. Add sign-in/current-user/logout/password-change UI using existing compact
   styling. Preserve bootstrap metadata behavior. Tests, env/Compose native
   commands, CI and operator/MFA docs updated. No new frontend dependency.
7. Run local/hosted gates; commit/push meaningful summaries, open stacked PR into
   P0-02 branch, do not merge or begin P1-02. Security-sensitive task remains REVIEW
   for human acceptance even after automated checks pass.
